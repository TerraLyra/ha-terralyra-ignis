# IGNIS public development roadmap

Prepared from the v0.26.3 baseline and compatibility extractions; not a release.

Completed baseline capabilities include NSW report calendars, optional QFD
reports, location-specific distances, refresh deadlines and replay identity
protection. Geographic/location primitives and HA attribute adapters have
compatibility tests. Existing local functionality remains available.

Priorities:
1. Validate repository relocation and preserve all existing HA identifiers/data.
2. Improve provider error/freshness diagnostics and fix demonstrated local bugs.
3. Preserve and test standalone local monitoring without a Cloud account.
4. Expand official Australian sources using verified provenance, timestamps and
   geometry; then assess sources in other severely affected regions.
5. Maintain public model/adapter boundaries without changing user-facing output.

Advanced service-side algorithms are outside this public roadmap. Optimization
remains paused. No deployment date or new release is promised by this snapshot.
