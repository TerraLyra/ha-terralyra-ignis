# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
include LSA SAF credentials, tokens, cookies, or other secrets in an issue, log,
traceback, screenshot, or test fixture. Revoke any credential that was exposed.

## Target repository setup

Private vulnerability reporting must be enabled and verified before this
migration snapshot is published. This text alone does not enable the feature.
